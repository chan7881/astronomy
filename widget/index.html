설치

  1. App Store에서 Scriptable 설치
  2. Scriptable → + → 아래 코드 붙여 넣기 → 이름 천문 예보
  3. 홈 화면 길게 누르기 → 위젯 추가 → Scriptable → 크기 고르기
  4. 위젯 길게 누르기 → 위젯 편집 → Script 천문 예보, Parameter에 종류
