# astronomy — 천문 관측 예보

오늘 밤 관측할 만한지, 무엇이 언제 보이는지를 한 화면에 보여 주는 정적 사이트.
<https://chan7881.github.io/astronomy/>

## 지금 상태

- 관측지(기본 포항 · 지명 검색 · 좌표 입력 · 현재 위치 · 즐겨찾기)와 5일 밤을 고를 수 있다.
  좌표는 검색창에 `36.02, 129.34`나 `36.02N 129.34E`로 넣는다(글자가 없으면 위도, 경도 순서).
- 판정(관측 점수 + 판정·최적 시간·달·구름·주의), 밤하늘 고도 곡선, 같은 시간축의 기상 띠, 시간별 상세 표, 천체 제원 표.
- 어두운 화면이 기본이고(바탕은 거의 검정, 색은 낮은 채도) 「적색」 단추로 적색 야간 모드를 켠다.
- 지명은 OpenStreetMap(Nominatim)과 Open-Meteo를 함께 찾는다(읍·면·동, 천문대도 나온다). 「위치」는 GPS 좌표를 그대로 쓰고 이름만 그곳의 읍·면·동으로 붙인다.
- 기상 띠의 구름 칸에 숫자(%)가 나온다.
- 시간별 상세 표는 그날 12시부터 다음 날 12시까지 25줄이고, 구름·시상·지수·제트 칸을 기상 띠와 같은 규칙으로 칠한다.
- 아이폰: 사파리 「홈 화면에 추가」로 전체 화면 앱이 되고, 위젯은 Scriptable 앱으로 띄운다(설치 안내 <https://chan7881.github.io/astronomy/widget/>).
  홈 화면 13종(작은 5 · 중간 4 · 큰 4)과 잠금 화면 4종. 위젯에는 적색 모드가 없다.
  기상만 보는 위젯은 작은 「날씨」 · 중간 「시간별」 · 큰 「기상」(설정값에 `기상`만 적어도 크기에 맞는 것이 뜬다).
  설정값에 `유리`를 더하면 유리풍(비스듬한 빛 + 밝은 테두리 + 반투명 칸)으로 그린다. iOS의 리퀴드글래스는 아니고 그려 넣은 것이다.
  「고도」(중간)는 곡선 아래 한 줄에 일몰·일출 시각과 달 모양 + 「42% 초승달」을 보인다(시안 B안, 11-16 승인).
- 시상은 ESO 파라날 관측(MASS-DIMM 2년)으로 보정했다 — 자유대기 = Dewan × 0.84 × 리처드슨 배율(meteoblue의 청천난류 기준 Ri ≤ 0.25를 연속값으로 바꾼 것). meteoblue는 식을 공개하지 않아 재료만 시험했다. 이론·검증·한계는 `docs/시상보정.md`.
- 테스트 74개(`npm test`), 변이는 본판 23종 · 위젯 25종 · 기상 위젯·유리풍·지명·현재 위치 33종 · 상세 표 8종 · 받아오기 5종 · 시상 보정 4종 · 리처드슨 배율 6종 · 고도 위젯 4종 모두 잡힘.

## 남은 일

- 한국 관측값은 보현산 SLODAR 평균(약 30밤, 1.22″)뿐이다. 이것과 견주면 사이트 식은 겨울 맑은 밤에 크게 낸다(1.57″, 주로 자유대기) — 평균 하나라 식은 그대로 두었다(`docs/시상보정.md` 3.6절). 밤별 관측값이 생기면 `tools/seeing/`으로 겨울 자유대기를 다시 맞춘다.
- 상세 표의 「정오~다음 날 정오」는 24시간을 더해 정한다 — 일광절약시간을 쓰는 외국 관측지는 시간이 바뀌는 날 끝이 1시간 어긋난다(한국은 해당 없음).

## 구조

본판은 빌드 없음(`index.html` + ES 모듈, 차트는 직접 그리는 SVG). 위젯만 묶음 파일을 만든다.

| 파일 | 역할 |
|---|---|
| `js/model.js` | 순수 계산 — 온위 기울기·불량층·제트기류·시상·관측 점수·밤 요약 |
| `js/sky.js` | astronomy-engine 래퍼 — 박명·고도 자취·출몰·제원·달 위상 |
| `js/api.js` | Open-Meteo 호출과 정규화(15분 캐시), 지명 검색·좌표의 지명 찾기 |
| `js/charts.js` | 고도 곡선·기상 띠 SVG |
| `js/places.js` | 관측지·즐겨찾기·테마 저장 |
| `js/view.js` | 한 밤의 자료 조립(본판과 위젯이 함께 쓴다) |
| `js/main.js` | 화면 조립과 이벤트 |
| `widget/data.js` · `layout.js` | 위젯 자료와 배치 — 그리기 명령 목록을 만든다(순수 계산) |
| `widget/app.js` | Scriptable에서 도는 부분 — 예보 받기, 그리기 명령을 DrawContext로 옮기기 |
| `widget/astro-widget.js` | 위 모듈을 합친 묶음. **`npm run build:widget`으로 만들고 함께 커밋한다**(안 맞으면 테스트가 실패) |
| `widget/loader.js` | 폰의 Scriptable에 붙여 넣는 코드 — 실행할 때마다 묶음이 바뀌었는지(ETag) 묻고 바뀌었을 때만 새로 받아 실행 |
| `widget/index.html` · `preview.html` | 설치 안내 · PC 미리 보기(`?p=36.17,128.98|보현산`) |
| `manifest.webmanifest` · `icons/` | 홈 화면 앱 설정과 아이콘 |
| `vendor/` | astronomy-engine 2.1.19 고정본(MIT) |
| `docs/concept.html` · `widgets-concept.html` | 승인받은 디자인 시안(위젯 시안은 주소 끝에 `?art`를 붙이면 폰 화면에 올린 모습). 색은 톤 다운 전 것이다 |
| `docs/tone-concept.html` | 지금 색의 본판과 기상 위젯(평면·유리풍)을 폰 화면에 올린 모습 |
| `docs/시상보정.md` · `tools/seeing/` | 시상 식의 이론·보정 보고서와 다시 맞출 때 쓰는 스크립트(받기 → 짝짓기 → 맞추기, meteoblue 재료 시험은 `meteoblue.mjs` → `meteoblue.py`, 보현산 관측과 견주기는 `bohyun.mjs`) |

로컬 실행: `python -m http.server 8741` 뒤 `http://localhost:8741/`.

## 계산

- **불량층**: 인접 기압면의 온위 기울기가 0.5K/100m를 넘는 대류권(200hPa 아래) 구간.
- **제트기류**: 300~200hPa 풍속 최댓값. 20m/s 이하 좋음, 30m/s 초과 나쁨.
- **시상(″)**: 자유대기는 Dewan(1993) 식(Cn² = 2.8 M² L0^(4/3))을 기압면 층마다 적분하고, × 0.84 × e^(0.034·(min(R, 8) − 2))(파라날 보정, R = Σ 두께km × min(1/Ri, 4))를 하고, 지표층 경험식과 5/3 제곱 합으로 합친다. **추정치**이고 밤의 경향을 읽는 용도다(`docs/시상보정.md`).
- **관측 점수**: 구름이 전체를 깎고 그 안에서 시상·투명도(에어로졸)·달빛이 가감한다. 천문박명 사이의 평균.
